# План разработки веб-приложения «Плати вовремя»

План основан только на требованиях [tz.md](tz.md). Разработка выполняется последовательно. На каждом шаге приложение должно оставаться запускаемым, а завершённый функционал — проверенным. Итоговый продукт состоит из `index.html`, `style.css` и `script.js`, запускается через `file://` и не зависит от интернета.

## Общий порядок проверки

- Сначала выполняются автоматические проверки логики, элементов страницы, кнопок, клавиатурного управления и сохранения данных.
- Для проверок используются контролируемые тестовые записи и автоматизированное взаимодействие со страницей в браузере. После проверки тестовые данные очищаются.
- После каждого изменения данных страница перезагружается в рамках автопроверки, чтобы подтвердить сохранение в `localStorage`.
- Ручная проверка пользователя запрашивается только для оценки внешнего вида, понятности и удобства интерфейса.
- Ошибки, найденные автоматическими проверками, исправляются до перехода к следующему шагу.

## Шаг 1. Основа приложения, данные и запуск без сервера — ✅ выполнен

- Реализовать чтение, запись, обработку повреждённых данных и ошибки квоты хранилища.
- Реализовать светлую и тёмную темы с сохранением выбора.
- Реализовать первый запуск с четырьмя демонстрационными записями и предупреждением о локальном хранении.

### Готовый результат шага

Страница открывается двойным щелчком по `index.html`, не обращается к интернету, показывает каркас приложения и демонстрационные данные, сохраняет настройки и корректно восстанавливается после перезагрузки.
